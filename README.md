# BioAgents Workshop @ IEEE BigData 2026

Website for the 1st Workshop on Multi-Agent Systems for Biomedical Discovery and Healthcare (BioAgents), co-located with IEEE Big Data 2026.

## Local Preview

Open `index.html` in any browser, or serve it locally:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deployment via GitHub Pages

This is a pure static site. Push it to a GitHub repository named `<org>.github.io` (e.g., `bioagents-workshop.github.io`) and GitHub Pages will automatically serve it at `https://<org>.github.io`.
